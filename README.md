## 本次新增

後台分別顯示AutoBac、百家輔助、聖甲之心在線數，另有跨站去重總在線及AutoBac執行中；每帳號只留「使用紀錄」入口，詳細設定與免責正文預設收合。三個網站各自驗證原登入，以同一白名單資料庫的暫存連線表統計跨站帳號聯集；只有AutoBac可計自動下注中。須三站全部部署各自更新包後才會涵蓋另外两站，不能以共用白名單本身冒充在線狀態。失敗顯示待同步、不假0；不收滑動紀錄，不更動原授權及下注規則。

成功開始時，實際策略、金額、配注、選桌、止損、止盈和分鐘設定快照也會回傳；到 `/admin` 對應帳號點「使用紀錄 → 使用／設定」查看。只打勾、取消或啟動失敗不當成成功開始；只新增設定紀錄表，不改白名單。聲明正文已明示設定留存。

馬丁止損必填且最低2,600。送單前合計本輪已結算損益、所有待結算本金的可能虧損與下一注，超過止損就停止新增下注；多桌共享額度。止盈、止損、時間到及下一注超過單筆上限都真正停止。全數正式結算後仍可手動選「新開始」，重設本輪累計、配注及時間；續接保留原輪累計，不偷偷繞過已達門檻。舊使用與下注紀錄保留。

使用者在DG風險彈窗手動勾選後，將事件記錄到原PostgreSQL的獨立資料表。管理員在 `/admin` 對應白名單帳號可看最新勾選時間、累計次數，並查閱完整當時聲明和版本。帳號取自原工作階段；時間由後端決定。同事件重試不重複累計，不存帳密、Token、Cookie、sessionId、IP或遊戲網址。單純開啟網站不會記錄，取消不抹除曾勾選的事實。這不是下注成功或法律效力保證。

勾選紀錄是非同步的，不新增下注門檻。後端成功保存才顯示已記錄；失敗最多嘗試三次，仍失敗會明示未同步，不補造過往紀錄。原授權期限、備註與啟用狀態不變。
